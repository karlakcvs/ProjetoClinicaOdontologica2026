1) COMO INSTALAR (igual às outras vezes)
----------------------------------------
1. Abra o Docker Desktop e espere "Engine running".
2. No VS Code: File → Open Folder → pasta DW2. Abra o terminal (Ctrl + ').
3. Rode:  docker compose down
4. (Recomendado) Copie a pasta mysql-data e cole como mysql-data-backup.
5. Apague a pasta src antiga e coloque a src deste zip no lugar.
   Troque também LEIA-ME.md, SEGURANCA.md e "Como rodar no VS Code.txt".
   NÃO mexa na pasta mysql-data (ela não vem no zip, de propósito).
6. Rode:  docker compose up -d --build
7. Abra http://localhost. Na primeira visita o banco se atualiza sozinho (versão 3).
   Nada é apagado: só os dados de DEMONSTRAÇÃO são ajustados.
8. Se aparecer tudo "sem estilo" ou com a versão antiga: aperte Ctrl + F5.

5) COISAS IMPORTANTES
---------------------
• Precisa de INTERNET para as fotos do antes e depois (vêm do Unsplash, gratuito, inclusive
  para uso comercial), além de Bootstrap, ícones e fontes. Sem internet, o espaço da foto
  fica em branco, sem quebrar a página.
• Para trocar uma foto do antes e depois: src/include/config.php → $CASOS_ANTES_DEPOIS.
  Use o código que aparece no endereço da foto: images.unsplash.com/photo-XXXXXXXXX.
  Se usar outro site de fotos, ele também precisa entrar na linha "img-src" do
  src/include/seguranca.php (proteção do site); senão a foto é bloqueada.
• Dente 3D: src/assets/js/dente3d.js. Para mudar a velocidade, procure "1 volta a cada 18 s"
  e troque o número 18 (maior = mais devagar).
• Antes de publicar o site de verdade: remover as avaliações de exemplo
  (Avaliações → "Remover avaliações de exemplo") e trocar os dados fictícios pelos reais.
