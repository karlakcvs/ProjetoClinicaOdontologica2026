1) COMO INSTALAR (igual às outras vezes)
----------------------------------------
1. Abra o Docker Desktop e espere "Engine running".
2. No VS Code: File → Open Folder → pasta DW2. Abra o terminal (Ctrl + ').
3. Rode:  docker compose down
4. (Recomendado) Copie a pasta mysql-data e cole como mysql-data-backup.
5. Apague a pasta src antiga e coloque a src deste zip no lugar.
   Troque também LEIA-ME.md, SEGURANCA.md e este bloco de notas.
   NÃO mexa na pasta mysql-data (ela não vem no zip, de propósito).
6. Rode:  docker compose up -d --build
7. Abra http://localhost. Na primeira visita o banco se atualiza sozinho (versão 4).
   Nada que vocês cadastraram é apagado: só dados de DEMONSTRAÇÃO são criados/ajustados.
8. Se aparecer a versão antiga: aperte Ctrl + F5.

Tecnologias continuam as mesmas: PHP + MySQL + HTML/CSS + JavaScript (Bootstrap).
